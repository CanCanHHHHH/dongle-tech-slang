# UX 体验走查报告(启发式评估)

- 日期:2026-09-29 · 走查版本:V7→V8 · 方式:清空进度模拟首次用户,实跑首页/学习卡/答对态/通关页,截真图评估
- 视角:第一次用户的情绪与摩擦 + ADHD 专项 + Nielsen 启发式
- 结论:体验底子好(干净、可读、无惩罚、节奏轻)。走查发现的高价值问题中,4 个已当场修复。

---

## 一、做得好的(保留)

- 阅读动线清晰:概念名 → 大白话 → 类比 → 提问 → 选项,自上而下不跳。
- 情绪基调对:全程"答错不扣分""想学就学",无倒计时、无失败态 —— 契合 ADHD。
- 通关页强:🎉 + "学会 5 个词" + 回顾清单(兼当小抄)+ 明确的"解锁下一关"。
- 版式克制:暖纸底 + 单主色,留白足,字号大,深浅色都成立。
- 导航有锚:每张卡有"← 关卡地图",随时知道退路。

## 二、发现的问题与处理

| 级别 | 问题 | 说明 | 处理 |
|---|---|---|---|
| 🔴 高(已修) | **核心奖励太平淡** | 答对只是绿字提示,缺"爽感"。对多巴胺驱动的 ADHD,奖励就是留存引擎 | ✅ 加了答对选项弹一下 + 进度点跳一下 + 通关 🎉 弹入动画(均遵守 reduced-motion) |
| 🟠 中高(已修) | **首次用户看到"空成就"** | 全新用户(0/39)却显示"🔥 连续 1 天""🏆 我的成绩卡",既像没挣来的、又把"开始"挤到下面 | ✅ 0 进度时改为欢迎引导"👋 从餐厅关开始",有进度后才显示成就统计 |
| 🟠 中(已修) | **视觉重心错位** | 实心橙的"成绩卡"按钮最抢眼,盖过真正的主行动(进第一关) | ✅ 成绩卡降级为描边次要按钮,实心橙只留给主路径 |
| 🟡 中(建议) | **"下一个"禁用态像主 CTA** | 答题前底部大按钮已灰,但仍可能吸引首次用户去点,点了无反应无解释 | 建议:答题前隐藏"下一个",或加一句"先选一个答案";本轮未改 |
| 🟡 低-中(建议) | **插图偏细偏小** | 类比配图是细线图标(78px),ADHD"看图优先"下辨识度和趣味不足 | 建议:换更粗/更有性格、略大的插画;本轮未改 |
| 🟢 低(建议) | **streak 计"打开"不计"学习"** | 只要当天打开就算连续,哪怕没学 —— 成就感偏虚,也影响指标真实性 | 建议:streak 绑定"当天完成≥1张卡";本轮未改 |
| 🟢 低(建议) | **首次无一句"怎么玩"** | 产品够简单,但一句超短引导能再降犹豫 | 欢迎语已部分承担,可再打磨 |

## 三、优先级建议(给下一轮)

1. **继续强化奖励反馈**(已开头):可选加轻音效开关、连对小连击提示 —— 这是留存最大的杠杆。
2. **答题前隐藏/弱化"下一个"**,消除"点了没反应"的困惑。
3. **升级插图**为更有性格的一套,兑现"看图优先"。
4. **streak 绑定真实学习**,让成就名副其实。

## 四、本轮已改清单(V8)

- 答对:选项弹动 + 进度点跳动 + 通关表情弹入(reduced-motion 下自动关闭)
- 首次用户:欢迎引导态,隐藏空成就统计与成绩卡入口
- 成绩卡按钮:实心 → 描边,让位给主行动
- (承接 PM 验收)streak 本地日期、全通关横幅、重置进度入口
