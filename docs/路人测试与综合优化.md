## 三、V9 本轮改动(综合优化)

1. **锁定关卡可点 + 轻提示**:点锁定关不再"死"无反应,弹 toast「先通关「上一关」就解锁这一关 🔓」。
2. **答题前隐藏「下一个」**:改为一句引导「👆 选一个答案,答对就能继续」;答对后按钮才实心出现 —— 消除"点了没反应"的困惑。
3. **开场收益导向**:文案改为「开会听不懂技术黑话?…让你跟程序员、产品能对上话」,先说好处再说方法。
4. **streak 绑定真实学习**:只在"当天完成≥1张卡"才计连续天数,不再"打开就算";成就名副其实,也让留存指标更真。
5. **图标更醒目**:类比配图加暖色底衬 + 略放大,兑现"看图优先"。

均通过浏览器实测,无 console 报错;reduced-motion 下动效自动关闭。
