# 懂了 · 技术黑话翻译器

**给非技术小白的技术黑话翻译器 —— 用生活场景讲成人话,ADHD 友好。**

开会听不懂"接口""字段""联调"?这里用一家餐厅、一座图书馆、一道门禁,把技术黑话讲成你能懂的话。
一屏一个词,答错不扣分,想学就学。

</div>

---

## ✨ 特点

- **场景串联,不是词表** —— 用故事(🍜餐厅 / 📚图书馆 / 🚪门禁…)串起一组相关概念,有上下文才记得住。
- **分层分级,螺旋加深** —— 🟢 Lv.1 认字 → 🟡 Lv.2 听得懂,同一概念在更高层再挖,不停留在基础。
- **ADHD 原生交互** —— 一屏一词、即时反馈、进度可见、**零倒计时、答错不扣分**。
- **闯关 + 词典双模式** —— 顺序解锁闯关学;也能"随手查"任意词,直接看解释。
- **智能复习 + 错词本** —— 答错的词自动进错词本、复习时优先重考,首答答对即"毕业";没有错词就随机抽学过的词(都不影响闯关进度)。
- **成就感** —— 进度环、连续学习天数(绑定真实学习)、可分享成绩卡。
- **零依赖** —— 单个 `index.html`,无框架、无构建、无后端,进度存在浏览器本地。

## 🚀 使用

直接用浏览器打开 `index.html` 即可,无需安装任何东西。

```bash
# 或本地起个静态服务(可选)
python3 -m http.server 8000
# 然后打开 http://localhost:8000
```

**快捷键**:数字键 `1/2/3` 选答案,回车 `Enter` 进入下一张。
